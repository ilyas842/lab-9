# Atelier North — Architectural Bureau Website

## Files
- `index.html` — semantic page structure and content
- `style.css` — responsive Grid/Flexbox layout, mobile menu styling, light/dark theme
- `script.js` — burger menu, theme switch, and client-side form feedback

## Run locally
Open `index.html` in a browser. An internet connection is needed for the remote architectural photographs and Google Fonts.

## Publish with GitHub Pages
1. Create a public repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Commit the files.
4. Open **Settings → Pages** and select deployment from the `main` branch and `/ (root)`.
5. Save, then wait for GitHub Pages to publish the public URL.

## Suggested commit history
Use separate commits as you build:
- `feat: add semantic page structure`
- `feat: style responsive architectural portfolio`
- `feat: add mobile menu and theme switch`

## Figma checklist
Create two frames: Desktop 1440 px and Mobile 390 px. Use a 12-column desktop grid and 4-column mobile grid. Check that CTA controls are easy to reach on mobile, and compare the exported design with the live page.

Note: the contact form uses browser validation and demo confirmation only. It does not transmit or store submissions on a server.
